Select .nodi.local.json inside your Nodi folder. In the Mac file picker, press Command + Shift + . to show hidden files. On Windows, enable View → Show → Hidden items; on Linux, press Ctrl + H. The file is read locally; credentials stay in this page’s memory until you disconnect or reload.

Open your Nodi service in Render → Environment. Copy each secret into its matching field below. These are the two secrets you generated when deploying.

Use NODI_ADMIN_TOKEN for the administrator and NODI_AGENT_TOKEN for the agent. Keep both private. You will need to reconnect after reloading this page.
